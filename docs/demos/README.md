# AVC 0.8 超级拼装交互 Demo

状态：历史界面评审稿。用户已批准正式开发，v0.8.0 实现见 `docs/V080_SUPER_ASSEMBLY.md`。本目录 Demo 继续仅使用模拟数据；其中早期联网找字幕设想已废弃。

双击同目录的 `avc-v08-demo.html`，即可在浏览器离线体验。它是独立网页，不需要启动 AVC 后端，不修改现有应用版本或配置。

- 顶部在“历史与撤销”之后增加“超级拼装”，页内切换软字幕嵌入与图片反查。
- 软字幕：勾选示例视频、展开轨道详情、选择字幕候选、处理同语言冲突、生成计划、体验模拟封装和取消。
- 图片反查：自制风景示例、用户本地选图 / 拖入 / 粘贴预览、模拟搜索，以及复制示例番号。无回填或预演集成。
- 可切换深浅主题，查看服务与工具设置；设置只在 Demo 当前会话中有效。

所有媒体记录和反查结果均为示例。图片不会上传，视频不会被读取或改写；网页通过内容安全策略禁止网络连接。搜索结果与所选图片没有实际匹配关系。

复制按钮使用浏览器剪贴板能力；受限时改为选中番号供手动复制，不虚报成功。选图仅支持 JPEG / PNG / WebP，限制 8 MB；本地预览会重新编码，不保留原图元信息。

图标来自运行环境已有的 Lucide 1.8.0，嵌入网页以支持离线运行，许可见 `LUCIDE-LICENSE.txt`。界面评审源文档见 `docs/V08_SUPER_ASSEMBLY_PLAN.md`。

正式实施前评审：导航与双标签是否合适、字幕列表和固定操作区是否清晰、另存成片是否符合预期，以及图片反查的上传区与结果密度。
