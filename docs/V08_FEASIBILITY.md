# v0.8 功能可行性考察

> 实施状态更新（2026-11-09）：v0.8.0 已实现本地软字幕嵌入和图片反查，具体范围见 [使用说明](V080_SUPER_ASSEMBLY.md)。字幕仅使用本地文件，图片结果仅复制番号；Whisper / 机翻暂缓。下文保留为开发前考察，不代表当前实施范围。

考察日期：2026-11-09。状态：设计研究，未将这些功能合入 v0.7.5。以下是基于当前源码和官方资料的实现建议；未运行外部图片搜索服务，也未上传任何图片或下载模型。

## 结论

| 计划 | 结论 | 推荐首版边界 |
|---|---|---|
| ffmpeg 嵌入字幕 | 可实现，工程量中等偏大 | 先做可切换的软字幕轨，MP4 / MKV；保留原文件备份，不默认烧录 |
| 本地 Whisper 机翻 | 可实现，但须更正“翻译”的定义 | Whisper 负责识别原语种或翻译成英语；中文字幕另接用户配置的本地翻译模型 |
| 图片反查番号 | 可实现，客户端接入工程量较小 | 顶部入口、用户自配 API、明确上传动作，只展示番号 / 相似度 / 时间点，默认不取远程缩略图 |

三项均可保持本项目无第三方 Node 运行依赖。ffmpeg、Python / Whisper 运行环境、模型和搜索服务由用户安装或配置，不加入安装包。v0.7.5 的固定计划、队列、报告及独立文件身份可作为共用基础，但长时间媒体处理需要扩展作业类型和取消逻辑。

## 1. 字幕嵌入

### 能力与格式

FFmpeg 官方文档支持显式流映射与流复制，可把外部字幕加入新的容器，同时复制原视频与音频流。容器和字幕编码须匹配；`-c copy` 不能保证任意字幕格式适配任意输出容器。ffprobe 可输出字幕流及标签的 JSON 信息。[FFmpeg 文档](https://ffmpeg.org/ffmpeg.html)、[ffprobe 文档](https://ffmpeg.org/ffprobe.html)。

建议软字幕首版支持：MKV 中加入 SRT / ASS 文本轨；MP4 中将新增文本轨转为 mov_text。仅对新增轨指定字幕编码，不能用一个全局字幕转码选项意外转换全部已有字幕轨。先检查现有附件、章节、音轨和字幕轨，生成逐轨映射；不兼容时提示另存 MKV，不能静默丢弃轨道。硬字幕会重新编码视频、耗时更长且不能关闭，应留为后续明确选项。

### 字幕选择

1. 先在**源视频原目录**检查同名有效 SRT；可随后扩展 ASS / SSA / VTT。
2. 根据用户选择的语言，检查同名语言后缀字幕，不能把不同语言视为重复。
3. 本地字幕无效时在预演中解释原因；没有可用本地字幕才使用已选网络候选。
4. 在计划中冻结字幕文件、内容指纹、语言、输出格式、流映射与输出路径；执行前重新检查。

“软字幕轨”与“画面上已经印有字幕”是两个问题。后者通常不能靠 ffprobe 判断；首版不承诺自动识别所有硬字幕。

### 避免重复

这是应用需要实现的逻辑，不是 FFmpeg 自动提供的去重开关：

- 先 `ffprobe -show_streams -show_format -of json` 检查已有轨道。
- 对准备加入的字幕规范化换行、文本和时间戳，计算 SHA-256；记录文件身份、字幕指纹、语言和任务结果。
- 尽量写入新增轨的标题 / 标签，同时在状态库保存同一标记；不同容器可能不保留自定义标签，因此不能只依赖标签。
- 对可提取的已有文本字幕轨，以相同规范化规则比较。完全相同则跳过；相同语言但内容不同则提供“保留 / 新增 / 明确替换”选择。
- ASS 与 mov_text 等转换会损失样式或改变文本表达，内容比较需要规范化；位图字幕不能直接等价比较，应显示“已有同语言轨，需确认”，不能擅自再加。
- 成功后再次 ffprobe 验证新增轨数量及主视频时长，只有验证通过才登记成功。第二次相同输入应没有写入。

### 文件安全与撤销

输出写到同目录唯一临时文件，取消 / 异常时清理临时输出。检测可用空间、文件占用和编码支持；校验后将原视频保留为可恢复备份，再进行替换。现有仅改名与旁车的 journal **不能直接承载视频重写**：需要 v2 媒体替换日志、备份指纹、恢复步骤和旧 v1 兼容读取。长视频即使流复制也会重写容器，耗时和空间开销主要与磁盘有关。

建议验收：MP4 / MKV、多音轨、已有文本轨 / 位图轨、相同字幕二次运行、不同语言、改过内容的字幕、中文空格路径、空间不足、取消、重启及撤销。

## 2. 本地 Whisper 与机翻

### 必须澄清的限制

Whisper 官方仓库说明：识别任务可转写原语言，`--task translate` 将非英语语音翻译成**英语**；它不是任意目标语言翻译器。`turbo` 未针对翻译训练，即使指定 translate 也会返回原语言。日语视频要输出中文字幕，不能只配置 Whisper。[Whisper 官方说明](https://github.com/openai/whisper#command-line-usage)。

建议顶部入口命名“字幕工坊 / 转写与翻译”，提供两条路径：

- 视频 → 本地 Whisper → 原语种 SRT；或视频 → 支持翻译的 Whisper 模型 → 英文 SRT。
- 原语种 SRT → **另行配置的本地翻译模型 / 本地兼容服务** → 中文 SRT，可选双语 SRT。

已有字幕时可直接翻译字幕，避免重新转写音频。翻译按 cue 编号批处理，保持时间戳；检查返回编号、缺句、重复、占位符和标点，失败分段重试，人工预览后再安装。

### 配置与运行

- 用户配置 Python / whisper 可执行路径、模型本地路径、设备、源语种、任务类型、输出语种和输出目录；不在项目中包含模型文件。
- Python / PyTorch / ffmpeg 是官方实现的外部运行环境，启动前做能力检查。模型缺失时提示选择本地文件，禁止未经用户同意自动下载。[Whisper 安装说明](https://github.com/openai/whisper#setup)。
- 后端用参数数组启动进程，不拼 shell 命令；可复用媒体路径校验。模型格式不通用，openai-whisper 的 checkpoint 与其他推理后端权重应区分适配器。
- 第一版选一个后端，优先用户自己的 openai-whisper Python 环境；faster-whisper / whisper.cpp 应以后续适配器独立加入并测试，不能把它们当作同一命令行。
- 独立长任务队列、分段进度、CPU / GPU 模式、取消整个子进程树、失败缓存及手动继续。缓存键包括文件身份、音频指纹、模型版本、语言与参数。
- 首版只生成 / 预览字幕，之后由用户选入嵌入计划，避免默认链式重写视频。

### 资源与质量

官方表格给出不同模型约 1–10 GB 的显存需求，但真实速度随模型、语言和硬件而变，不能向用户保证固定处理时间。长时静音、背景音乐、多人对白等需保留低置信度提示和人工修订；不把“识别完成”写成“准确翻译完成”。[Whisper 模型表](https://github.com/openai/whisper#available-models-and-languages)。

## 3. 图片反查 API

### 仓库真实提供什么

所给仓库 `poisonhs/avscan-frame-search` 是调用 avscan.cc 的 Python CLI / Agent Skill，README 中未提供可在本地部署的完整搜索索引服务。用户能配置兼容 API 地址，但不能承诺克隆该仓库就获得自建搜索后端。[仓库 README](https://github.com/poisonhs/avscan-frame-search)。

README 描述的协议：`POST /search`，`multipart/form-data` 字段 `file`，图片不超过 8 MB；响应包含 `results`，每条有 `video_code`、`best_similarity`、`frames`（`image_name` 与 `similarity`）。服务端最多返回 20 条、无分页。可据此独立编写 Node 接入器，无须复制或捆绑上游 Python 脚本。接口的实际可用性、认证要求及配额须在用户配置后实测；README 同时提到 429 限流，因此不宣传“无限调用保证”。[接口说明](https://github.com/poisonhs/avscan-frame-search#核心接口直接用也可以)。

### 推荐界面与接入

1. 顶部“以图查番号”打开粉樱风格面板：本地选择 / 拖入图片、本地预览、已配置服务域名、上传说明。
2. 默认 API 地址为空。用户在设置中输入完整 search URL、可选认证头、超时与结果数；配置与密钥只存在本机，导出诊断要脱敏。
3. 点击“上传并搜索”才将图片传给配置的服务；仅选择图片不发送请求。可本地压缩 / 去除 EXIF，但应在发送前让用户看到最终图片。
4. 后端转发 multipart，限制大小、类型、请求超时和响应体大小，处理 400 / 429 / 服务异常。用户配置的远程 URL 需拒绝不合理协议和跨域重定向，不把密钥转发给其他站点。
5. 默认结果只展示番号、相似度、时间点。相似度不是正确率，纯色图也可能虚高，用户确认后才能填入目标文件并重新预演。
6. 不内置截图、缩略图、索引或模型，不默认请求热搜 / 远程帧图；测试仅使用自制几何图片和模拟 JSON。若将来加入缩略图，应明确是第三方内容的可选在线展示。

本次未看到可确认的上游许可证文本，因此不复制其实现；独立实现公开接口协议，并在发布前复核上游服务条款。此项难点主要在外部服务稳定性、图片上传行为和结果确认，非 GUI 本身。
