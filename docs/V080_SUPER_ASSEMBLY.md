# v0.8.0 超级拼装

顶部入口位于“历史与撤销”之后，分为“字幕嵌入”和“图片反查”。继续使用原有中英文、字号、壁纸与主题偏好。

## 本地软字幕嵌入

1. 打开“工具与接口设置”，填写 FFmpeg、FFprobe 命令名或完整路径，保存并检查工具。两个工具都需可执行；项目不附带二进制或安装器。
2. 浏览或输入视频目录后点击“读取目录”，也可导入工作台当前勾选的文件。只读取本层目录，显示最多 1000 个视频，一批最多选择 100 个。
3. 默认优先选择源目录同名 `.srt`，其次是同名加语言后缀的 SRT。每项可改选发现的候选，或填写其他本地 SRT 完整路径。路径必须在 `fs.allowedRoots` 授权范围内，并校验解析后的真实路径。
4. 选择 MP4 / MKV、字幕语言和轨道名称；可将新增轨设为默认。需要其他输出位置时，填写已存在的授权目录。
5. 点击“分析字幕与重复轨”。此时只读媒体并保存计划，不生成成片。分析会检查有效 SRT、视频结构、已有字幕、重复内容和输出占用。
6. 确认计划后开始嵌入。视频与音频使用 stream copy，不重新编码画面或烧录字幕；MP4 新字幕为 mov_text，MKV 为 SRT。

字幕来源只有本地文件。缺少字幕时，请先去工作台下载，然后回到此页重新读取目录；嵌入工具不会联网寻找字幕。

默认输出 `原文件名.softsub.mp4` 或 `原文件名.softsub.mkv`，源视频与旁车字幕保持原样。已有输出会阻止执行，不会覆盖或自动改名。需要输出文件系统支持硬链接；不支持时会失败并保留源视频，不使用可能覆盖目标的回退操作。

相同字幕通过抽取已有文本轨，比较归一化后的时间戳与文本检查；相同内容会跳过。其他已有字幕（包括不可抽取的图片字幕）需要勾选“保留已有字幕，并添加新轨”。不会自动替换、删除或重新编码旧轨。MP4 中无法原样保留的字幕 / 附件 / 数据轨会阻止执行；可尝试 MKV。MKV 也会拒绝已知不支持直接复制的轨道结构，其他不兼容情况由 FFmpeg 明确报错。

计划保存源文件的文件身份、大小与修改时间、字幕原始字节 SHA-256、输出目录及工具路径。修改设置后需重新分析；执行前和发布输出前再次校验。计划有效期 24 小时，一次执行后不可重复使用。源视频不做全量预哈希，避免分析阶段读取整部影片。

执行分为准备、封装、轨道与新增字幕校验、输出 SHA-256、发布。临时输出位于目标目录下的独立 `.avc-mux-*` 文件夹，成功后以拒绝覆盖的硬链接操作发布。取消等待实际子进程退出，再删除当前未完成临时文件；已完成输出保留。

任务进入“历史与撤销”，可查看字幕嵌入专用报告并导出 JSON / HTML。撤销仅删除仍与记录 SHA-256、大小及文件身份一致的输出；已修改或替换的输出保留并报告失败，源文件始终保留。v2 媒体日志与旧改名日志分开识别；发布前先记入输出指纹，因此发布成功后意外退出仍能通过日志撤销。硬退出可能留下 `.avc-mux-*` 临时目录，需要确认未运行后自行清理；不会自动恢复封装或续跑中断任务。

封装是完整媒体读写，会额外占用接近视频体积的磁盘空间。校验与撤销的 SHA-256 还会读取成片；大视频在“计算指纹”阶段耗时是正常现象。字幕样式转换受目标格式限制，复杂 ASS / SSA 新字幕不在本版导入范围内；SRT 的少量 HTML 样式也可能因播放器而异。

## 图片反查

1. 在“工具与接口设置”中填写完整搜索 URL，或点击“使用 avscan.cc”填入 `https://avscan.cc/search`，再保存。默认地址为空，不会自动访问服务。
2. 接口支持 HTTPS；本机调试地址可用 HTTP。可选鉴权密钥、`Authorization` / `X-*` 鉴权头、3–120 秒超时、1–20 条展示数量和 HTTP CONNECT 代理。`Authorization` 密钥自动加 `Bearer `，自定义 `X-*` 头使用原值。
3. 选择、拖入或粘贴 PNG / JPEG / WebP。原文件不超过 8,000,000 字节、2500 万像素；浏览器重新编码 JPEG 去除元数据，最长边最多 2048 像素，最终预览与上传字节一致。
4. 点击“开始搜索”才上传。结果仅显示番号、相似度与命中时间，并提供“复制番号”，不会关联预演、修正字段或改名。

后端独立实现上游公开协议：单次 `POST`，`multipart/form-data`，字段名 `file`。解析 `results[].video_code`、`best_similarity`、`frames[].image_name`；相似度原本就是 0–100 百分数。服务最多 20 条，无分页；数量设置只裁剪本地展示。

不获取远程缩略图、热搜或统计。上传不自动重试，不跟随重定向；若服务返回 3xx，请配置最终接口地址，避免在不同目的地重复发送图片。429、鉴权失败、超时、网络异常与返回格式错误会明确提示。取消只终止本地连接，无法撤回第三方已经收到的数据。

截图与搜索结果只在当前会话内存中存在，不写入历史、缓存或后端磁盘。工具配置单独保存在数据目录 `assembly-settings.json`，密钥在独立 `assembly-secret` 文件，接口响应不返回密钥。它不是操作系统密钥保险库；请妥善保护本地数据目录。常规配置导出、诊断和备份不包含这两份设置文件。备份包含封装计划、任务报告与撤销日志，不包含视频输出本身。

无需克隆上游项目、安装 Python 或部署模型。本项目不附带影片、截图、搜索索引或模型。

接口资料：[avscan-frame-search API 说明](https://github.com/poisonhs/avscan-frame-search/blob/main/references/api.md)。第三方服务可用性和匹配准确率由服务本身决定。
