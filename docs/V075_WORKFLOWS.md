# v0.7.5 工作流升级

发布日期：2026-11-09。目录配置档废案。根据实际使用反馈，问题中心与新增队列面板已撤回。

## 操作入口

| 功能 | 入口与用法 |
|---|---|
| 只补缺项 | 工作台“本轮选项 → 处理方式”。分别选择元数据、主字幕、附加语言字幕、封面；默认保留文件名，另行勾选才重新生成名称。 |
| 字段修正 | 点击文件行打开详情，在“元数据 → 修正与锁定”编辑。修改后默认锁定；解锁允许后续来源刷新覆盖，恢复来源清除人工值。 |
| 字幕候选对比 | 详情“列出候选字幕 → 对比两个候选”。选择两个候选和同一个时间窗，分析后将其中一个选入已完成的操作计划。 |
| 冲突解决 | 仅在预演有冲突时显示“解决预演冲突”，或应用时自动定位未解决冲突。可整批 / 单项选择后缀、跳过、自定义名称；改番号会要求重新预演。 |
| 缓存与维护 | 设置 → 缓存与维护，提供删除缓存、一键重启前后端。操作前有确认，运行中不可执行。 |
| 可读报告 | “历史与撤销 → 查看报告”。区分预演 / 实际结果，筛选失败、写入及保留项；可打印或导出离线 HTML，原 JSON 和日志仍保留。 |

## 计划与修正

- 预演将操作计划保存在应用数据目录的 plans 子目录。计划包含文件身份、size / mtime 指纹、人工修订号、配置快照、选择范围、有效元数据、主字幕缓存及最终目标。
- 应用必须引用 GUI 的计划 ID 和修订号，使用该计划的配置与文件集合；不会重新查询元数据或自动改换主字幕候选。
- 源文件、修订、旁车或目标占用改变时，任务转为“待复核”。请重新预演；不会默默选一个新的文件名执行。
- 为兼容既有 CLI / API 调用，旧版无 planId 的直接应用接口仍存在。新版 GUI 始终发送 requirePlan；新集成也应使用固定计划。
- 手动修正独立保存于 SQLite records / corrections 表，schema v3。相同番号的两个文件有不同身份；程序改名与撤销转移身份，外部替换文件不会按番号或大小继承修正。
- 修改番号时清除旧来源、字幕和封面关联，用户可选择清除或保留其他人工锁定字段；保存修正本身不写入视频目录。
- 媒体撤销不撤销人工修正。需要恢复字段时使用独立“修正历史”。

## 只补缺项的边界

主字幕和语言后缀字幕须能解析为有效 SRT；封面须通过 JPEG / PNG / WEBP 文件签名检查。未知语言会提示不能确认，而非承诺语义识别。意图留空且锁定的字段视为人工决定。

有效主字幕和封面会被保留，缺封面不会导致重新下载主字幕。补缺模式不自动嵌入封面。字幕 / 封面的独立操作也会记录撤销日志，撤销可恢复之前的旁车备份。

如果明确勾选重新命名，有效旁车会复制到新名称旁，保留原旁车；新副本记入撤销日志。附加语言沿用“应用时才查询”的既有规则，预演固定其配置与目标占位，不保证预先取得每种语言；报告记录实际取得的结果。

## 精简、滚动与维护

删除顶部待处理、任务队列和“将当前选择加入预演队列”；后者只是额外排队入口，与勾选后预演重复。移除问题聚合 / 忽略、暂停 / 排序 / 复核重入队及排队快照逻辑。普通预演和应用继续使用既有串行执行、取消和历史；重启时未完成记录标为中断，不自动续跑。旧 queue-state 文件和 issue_ignores 表不再使用，升级时保留原文件及数据，不降 schema、不动人工修正。

“解决预演冲突”处理目标占用、同批重名与疑似重复，可选后缀、跳过或自定义名称；与勾选后预演不同。入口只在有冲突的预演汇总出现；应用时仍保留防覆盖检查。

右侧上方进度、选项、来源与日志使用独立滚动区，隐藏滚动条但保留滚轮、触摸与键盘操作；应用 / 取消 / 导出位于固定底部。桌面高度随视口与当前位置适配，窄屏使用有限高度的滚动区。

缓存清理仅删除 codes 查询缓存、subtitle-previews 中的散列 JSON 临时文件以及封面代理内存缓存。保留记录、人工字段与修订历史、字幕落地记录、plans、jobs、journal、配置、媒体与浏览器壁纸；遇到链接缓存目录拒绝处理。清理后当前页面预演清除；内容大小不是物理磁盘释放量。

启动脚本 / 直接 node 启动时，由轻量父进程管理后端工作进程。重启仅在空闲时执行，工作进程关闭后以原端口、host、配置和 cwd 重新启动；浏览器通过 instanceId 判断恢复后刷新。由其他程序 import 的 startServer 默认不支持重启，除非注入生命周期回调。运行、等待任务或其他 API 操作中，维护返回 409；未保存的设置应先保存。

## 报告与兼容

历史报告只引用任务当时记录的事实。旧报告没有的细节显示为“未记录”，不能根据计划目标推断写入成功。HTML 导出内嵌样式和筛选脚本，不引用远程图片或脚本，并转义文件名 / 元数据。

旧 SQLite 自动备份迁移，旧 journal v1 和历史 JSON 继续读取。v0.8 的视频流重写需要另行设计 v2 撤销，不属于此版本。

后端数据备份包含 plans（固定计划与主字幕缓存）、jobs 和 SQLite 人工修正；过期的候选分析临时缓存不备份。HTML 报告跟随界面当前语言、主题和字号导出。
