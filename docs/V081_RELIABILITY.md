## 修复内容

| 编号 | 变更与用户可见行为 |
|---|---|
| A01–A03 | 类型化日志在文件操作前保存意图；同卷普通文件移动拒绝覆盖目标；旁车按历史指纹分步撤销，保留后来修改的文件，重复撤销不重复删除。中断后保留可调和状态，损坏日志拒绝覆盖。 |
| A04、A06、A21 | 数据目录共享写入所有权；超时、取消和关闭等待在途操作收敛；报告、快照保存后才公开终态，启动器等待自有 worker 关闭。 |
| A05、A09、A18 | 内部封面嵌入替换保留同一记录、字段锁和历史；同路径外部新文件刷新身份后再判断跳过。撤销完成的视频路径独立投影回状态库，旁车仍有冲突时也不会把记录留在错误路径。 |
| A07、A08 | 请求校验实际监听地址的 Host、Origin 和精确内容类型；拼装读取保留来源保护。授权读取检查路径与句柄身份；启动器验证公共请求后再转发内部地址。 |
| A10–A12 | 测试与覆盖率统一递归发现；修复日期模板的发布引用检查；公开包清单明确列出资源，排除内部数据和截图，同名 ZIP 拒绝覆盖。 |
| A13、A14 | HTTP 响应验证长度、分块与完整结束；连接、TLS、定时器和监听器按尝试清理，旧尝试关闭后再重试。 |
| A15 | SQLite 使用一致快照和摘要清单；恢复按整代处理，默认保留已有目标，显式覆盖恢复保留旧代和恢复阶段。 |
| A16、A17 | 实际应用绑定已确认的文件范围和选项，单文件需独立预演；候选、分析和安装绑定文件身份及详情上下文，迟到结果不串入其他文件。 |
| A19、A20 | 时间轴按总整数毫秒处理进位，保留字幕编号、正文与顺序；各语言安装前验证结构和时序，字幕候选按完整番号匹配。 |

- 修复阶段冻结源码在 Node 24.22.1 和 26.13.0 下各执行预先审核的 26 个完整安全测试文件：**272 通过、0 失败、0 跳过**。这是选定集合，不能写作项目完整 `npm test` 通过。

- 原生目录入口 `node --test tests/` 在 Node24 的独立目录夹具中失败，Node26 的目录夹具通过。正式 `npm test` 现在使用显式完整发现入口，避免依赖这一版本差异。
- 另有明确选择的旧 server / integration 用例、合成文件和独立 SQLite、正常同源服务及界面操作证据；它们不与 272 项重复相加，也不代表所有界面状态均已遍历。
- 修复阶段完成语法、公开文件清单、隔离 full / slim / docs 打包、VERSION 文件摘要，以及解包后的合成文件 CLI / API 扫描检查。版本归档阶段的相关测试与检查单独记录，不替代完整套件。
- A07 / A08 / A13 / A14 的拒绝和故障验证使用静态分析与内存替身；真实跨源、链接绕过、异常 TLS / 代理和系统句柄泄漏实验未执行。
- 更多动效的 2026-11-10 历史页面检查属于早期视觉验证，见 [MORE_EFFECTS](MORE_EFFECTS.md)，不能作为本次修复后的全项目验收。

## 尚未完成与使用限制

- **完整项目 `npm test`、完整覆盖率和远端 CI 未通过本次记录验证。** 完整套件含当轮不允许执行的能力；相关原用例没有为制造通过结果而删除或默认跳过。
- 现有 Node22、FFmpeg 和 FFprobe 在验证机器上启动失败，错误为 Windows `0xC0000142`。Node22 兼容性、真实 MP4 / MKV 封面嵌入和部分真实媒体取消行为仍未完成验证，模拟结果不抵扣真实工具门。
- 安全移动只支持本地同卷普通文件及所需硬链接能力；跨卷、网络盘和能力不足输入保守拒绝。操作期间源文件需无不合作外部替换；协作所有权不能排除任意外部进程。
- 授权读取依赖祖先目录稳定；现有 Node 句柄能力未证明消除恶意祖先交换。文件同步不等于所有平台目录耐久性，真实断电及全部恢复中断排列没有验证。
- 封面嵌入按用户选择覆盖当前媒体，**不保存嵌入前媒体版本**。字段锁和历史会迁移；撤销可恢复路径和有依据的旁车，嵌入封面保留，不能恢复嵌入前字节。
- 缺少历史指纹的旧撤销日志保留供人工复核，不自动移动或删除文件。未知租约不自动抢占；不理解新日志和恢复中间态的旧程序不能继续写入相同数据目录。
