# 更多动效（实验中）

本次为正式前端增加可选视觉模式。首次默认关闭，此后记住此浏览器的手动选择。

状态：已并入 v0.8.1（2026-11-11），与本次可靠性修复统一记录于 [0.8.1 更新日志](../CHANGELOG.md#081---2026-11-11)。应用内更新日志同步展示 0.8.1 与全部历史版本；“实验中”表示视觉模式仍有验证限制，不再是未分配版本的工作区增量。

## 体验方式

正常启动 AVC，或打开已经运行的本地界面 `http://127.0.0.1:17890/`。
点击顶部的 **更多动效（实验中）** 开启，再次点击返回简洁模式。
已打开的旧页面需要刷新一次。

开启后隐藏“主题”按钮和左下角“外观与氛围”入口，使用固定烟紫色配色。
退出后恢复原有主题、壁纸、面板和天气设置。模式切换不重建工作台，也不清空输入、勾选、任务和滚动位置。
模式偏好单独保存在 `avc.effects.v1`，与主题及 `avc.appearance.v2` 分开。

## 界面和交互

- 顶部导航使用局部背景模糊、玻璃亮边、内高光及可移动选中胶囊。
- 页面主体保留原结构，通过面板材质、边框、阴影和语义色统一视觉。
- 列表、输入框、日志、弹窗、抽屉和提示具有较实的文字承托。
- 模式切换约 520 毫秒；支持浏览器原生画面过渡时，同步过渡材质和导航位置。其他环境保留淡化与位置过渡。
- 页面背景约 380 毫秒交叉淡化；图片准备好后再交接，连续切页只保留最后的请求。
- 普通悬停与按压保持短促反馈，不增加持续扫光、拖尾或面板呼吸。
- 超级拼装设置弹窗固定保留底部操作区，内部内容单独滚动。

## 播放与回退

只播放当前页氛围；其他页、失焦或隐藏时暂停。尊重系统“减少动态效果”：隐藏粒子，保留静态画面和材质。
无持续 JavaScript 帧循环，不增加外部运行依赖。背景仅在用户开启该模式后开始加载。
鼠标视差仅在移动事件发生时合并更新，平滑过渡由 CSS 完成；关闭模式、切到后台或改变输入设备时清除位移。
不支持背景模糊时采用较实的导航底色；图片加载失败时保留深色氛围底色。

简洁模式的背景轮播、时间联动、樱花和花雨在新模式中暂停；退出后恢复。
启动动画与此前两个独立场景 Demo 保留，没有接入或修改。

- 使用临时展示数据验证输入框节点、文件列表、选中集合、任务对象及滚动位置保留；未用用户媒体执行重命名或撤销。
- 覆盖中文默认字号，以及英文 20px 字号在 1440、1024、768、390 像素窗口下的四页导航与横向溢出。
- 覆盖更新日志、目录浏览器、超级拼装设置弹窗，以及窄屏大字号的弹窗底部操作区。
- 验证失焦／恢复事件处理、减少动态效果，以及缺少原生画面过渡时的切换回退。
- 本地可选证据：截图保存在工作区的 docs → screenshots → local → more-effects 目录，结构化结果为该目录下的 `checks.json`。这些产物已被 Git 忽略，不随仓库分发，干净克隆不包含它们；`work-list.png` 为示例数据，非用户真实媒体记录。

本次没有进行长期运行或跨显卡性能测量；浏览器检查中的失焦使用真实事件处理路径的模拟事件，未声称执行了操作系统最小化实测。
这些结果只证明所列条件下的检查通过，不能替代对媒体写入、撤销、并发、启动恢复及外部服务的独立项目审计。

## 后续维护

主要实现：`web/effects-bootstrap.js`、`web/effects.js`、`web/effects.css`。
现有模块仅接入页面通知以及外观／花雨的暂停与恢复接口。

可选浏览器检查脚本：`tools/check-effects-ui.mjs`。需要开发环境已安装 Playwright 和 Edge，应用运行本身无需这些依赖。
如 Playwright 不在项目依赖中，可将 `AVC_PLAYWRIGHT_PATH` 指向已有包；运行 `node tools/check-effects-ui.mjs`。
检查使用独立临时配置、数据库和浏览器存储，不修改用户配置与媒体，结束后清理其专用临时目录。
