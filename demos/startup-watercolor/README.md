# AVC · 一笔春色：独立启动动画 Demo

直接在浏览器中打开 `index.html`，或在项目根目录运行：

```powershell
node demos/startup-watercolor/serve.mjs
```

浏览器打开命令输出的本机地址。全部资源均在本地，不调用业务 API，也不修改正式启动页。

动画标准速度总长 **8.6 秒**，素材解码及首次渲染在播放前完成：

- 0–2.9 秒：先慢描中央发缕，让视线落到人物，再连续加速展开周围轮廓；五官与指尖放慢，衣袖和飘带再提速，尾部线条延续到约 3.6 秒。
- 2.9–5.5 秒：八个区域从同一湿色起点错峰延伸，后续遮罩先沿已上色的路径推进，再向头发、肩部、手部和衣摆扩散。主体、背景与外沿色晕来自同一张完整画面，随同一遮罩同步显色。
- 5.5–8.0 秒：颜色继续扩散至外围，线稿逐渐退入完整画面；外沿随色块连续展开，末段停止动画后保留同一画面。
- 8.0–8.6 秒：完整成画短暂停留；Demo 随后保持最终画面，方便检查。

线稿有十个区域的独立起笔与笔速参数，每笔采用平滑变速曲线；线稿与遮罩共使用八种速度曲线，并对遮罩宽度扩散单独编排。预览与正式启动页共用 `../../web/startup-art.js` 的 `speeds`、`inkRegions` 与 `washes` 参数；晕染连续路径位于 `washRoutes`。
支持暂停、重播、阶段跳转、拖动进度、倍速以及减少动态效果。

线稿和精细成画从 `../yuyuko-svg/index.html` 提取，保留原路径与统一坐标。原始完整成画保存为 `assets/painting.svg`；构建时通过浏览器预渲染成透明的 `assets/painting.png`（1830 × 2660），播放时复用该图像缓存，避免每帧重绘复杂 SVG。
原画署名为 sai / 东方 Project，与源 Demo 保持一致。

修改 `template.html` 或源素材后，执行 `node demos/startup-watercolor/build.mjs` 重新生成预览页和成画素材。
构建需要 Playwright 和 Chrome：优先读取本地 Playwright 包，也支持 Codex 内置运行时；可用 `AVC_PLAYWRIGHT_PATH`、`AVC_CHROME_PATH` 指定路径。直接观看已生成的 Demo 不需要安装这些依赖。

正式启动页已接入同一动画。源素材重新构建后，在项目根目录执行 `npm run build:startup` 同步启动页 SVG 和图片到 `web/`。正式页仅显示“少女祈祷中”和“进入”，素材准备好后停顿 0.6 秒再播放；后端就绪且动画播放完整后自动进入主页，按钮可提前进入。后端初始化失败时同一按钮负责重试。便携版直接包含 `web/` 下的全部启动资源，无需预览目录或构建依赖。
“少女祈祷中”字号为 20px，“进入”字号为 18px；按钮采用 12px 圆角矩形和淡玫瑰色实底，与纸色背景区分。按钮在页面出现 1 秒后开始用 1.6 秒淡入，淡入完成且后端就绪后才可点击。减少动态效果模式仍保留 1 秒延迟，并省略淡入。

入场前 1.7 秒用统一的时间映射从慢到快展开，首笔中央发缕使用独立的持续描绘；脸部与手部保留较慢的绘制和扩散。

衣料平滑调整：帽子、衣袖、飘带与和服连续起笔，单笔约 0.10–0.29 秒。描线速度与铺色速度采用宽峰曲线，去掉中段近乎停住后的二次冲刺；衣料遮罩推进约 1.35–1.45 秒，宽度扩散使用独立、连续的渐变曲线。总长仍为 8.6 秒。播放进度约每 30 毫秒更新一次，减少控制条的阶梯感。

晕染衔接调整：背景遮罩去掉互不相连的三条子路径，改为从面部湿色起点沿头发、肩部向外绕行的单条连续路径。衣袖和衣摆也补上从已上色区域出发的连接段，避免在空白处独立起色。衣料遮罩推进约 1.35–1.45 秒，外围从 4.15 秒起连续扩散约 2.15 秒。帽沿、发侧和衣摆的扩散范围覆盖外沿色晕，去掉了末段整层成画淡入，从源头消除突然补边。
